LapSmith Relay setup

Installs LapSmith Relay 0.1.4

You need:

  • an M5Stack AtomS3 Lite or Atom Lite,
  • a USB-C cable that carries data (not a charge-only one),
  • Chrome or Edge on a computer. An iPhone or iPad can't install it. Chrome on an Android phone may work, but hasn't been tried yet.
  1. Plug the Atom in.
  2. Press Install. Chrome lists the Atom: an AtomS3 Lite is called USB JTAG/serial debug unit. Pick it, press Connect, then confirm. It takes about a minute. Keep it plugged in until it says it's done.
  3. Unplug it, then power it from the battery or any USB supply.
  4. In the LapSmith app, open Settings › Bluetooth relays. The first phone pairs with a new relay without pressing anything.
This browser can't reach USB devices. Use Chrome or Edge on a computer. This page has to be opened over https to install.
This is for a new board. Installing erases the Atom, so a relay that is already set up forgets every phone. To update a relay, use the LapSmith app. If you do reinstall one, first forget LapSmith Relay on each iPhone that used it (Settings › Bluetooth, ⓘ, Forget This Device), or it can't pair again.

If it won't connect

  • The list is empty: unplug the Atom and plug it in again, or try another cable. Many USB-C cables only charge.
  • It fails straight after you pick the Atom: another program has it open (Arduino IDE, M5Burner, a serial monitor). Close that program, then press Install again.
  • It's in the list but the install fails: on an AtomS3 Lite, hold the small reset button on its side (not the big button on top) for about 2 seconds, until the small green light comes on, then press Install again. That puts it into download mode by hand.
